FILE: fibon_form.php

WHAT CHANGED
Signup no longer runs SHA() inside an INSERT string. The password is hashed first, then every field is bound with ?. The two password boxes must match on the server, not only in JavaScript. A taken username is rejected. The parent email contains the username only.

      $insert->bind_param("ssssssssss", $firstname, $lastname, $email, $student_name, $student_age, $student_gender, $username, $password_hash, $current_year, $english_level);
      $insert->execute();
      $insert->close();

          "Use the password you chose on the enrollment form. Otutor does not send passwords by email.";

      }

      }
